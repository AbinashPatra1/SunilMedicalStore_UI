# Medical Store App

## Objective

Android application for a local pharmacy.

## Tech Stack

Flutter

Riverpod

GoRouter

Firebase Authentication

Firebase Messaging

Azure Blob Storage

ASP.NET Core Backend (future)

MySQL (future)

## Coding Guidelines

Use Material 3.

Follow feature-first architecture.

Use Riverpod.

Keep widgets small.

Prefer StatelessWidget.

Separate UI and business logic.

No mock data inside widgets.

Repositories provide data.

Write production-quality code.

Avoid unnecessary packages.

Always explain changed files.
